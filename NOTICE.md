# Notice

This repository contains the implementation of SEDRRG for radiology report generation.

Parts of the evaluation code are adapted from commonly used captioning evaluation utilities, including BLEU, METEOR, ROUGE-L, and CIDEr implementations under `pycocoevalcap/`. Their original license files are retained where available.

Users are responsible for obtaining IU X-Ray and MIMIC-CXR datasets from their official sources and complying with the corresponding data-use agreements.

This repository does not distribute medical images, reports, protected health information, or pretrained checkpoints derived from restricted clinical datasets.
